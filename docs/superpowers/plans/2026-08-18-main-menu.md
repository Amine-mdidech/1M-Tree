# Main Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a real main menu / title screen (Continue-or-Play, New Game with confirmation, a trees-planted stat, an upcoming-milestones list, Settings, Quit) shown before gameplay, instead of dropping the player straight into `SampleScene`.

**Architecture:** A new `MainMenu` Scene (Build Settings index 0, `SampleScene` becomes index 1) contains only a `MainMenuUI` panel, a `SettingsUI` instance, and its own `AudioManager` — no gameplay managers. `MainMenuUI` reads `save.json` read-only (via a new `SaveSummaryReader` static helper) to decide Continue-vs-Play, show the trees-planted count, and filter the milestones list; it never writes the save file. Play/Continue and New Game both hand off via `SceneManager.LoadScene("SampleScene")`, whose existing `SaveManager.Start()` → `LoadGame()` remains the sole authoritative load path, completely unchanged.

**Tech Stack:** Unity 2D URP, C# (single `Grove.Runtime` asmdef under `Assets/Scripts`), UI Toolkit (UXML/USS) for the panel, NUnit EditMode tests under `Assets/Scripts/Tests` (`Grove.Tests` asmdef). Scene/GameObject/asset creation and wiring is done live in the Unity Editor via the UnityMCP tool bridge (`manage_scene`, `manage_gameobject`, `manage_components`, `manage_asset`, `manage_build`) — this project has no other mechanism for creating a Scene or wiring Inspector references outside the Editor.

**Spec:** `docs/superpowers/specs/2026-08-18-main-menu-design.md`

## Global Constraints

- `MainMenu` is a **new Scene** (`Assets/Scenes/MainMenu.unity`), added to `ProjectSettings/EditorBuildSettings.asset` as index 0; `SampleScene` becomes index 1.
- **No persistent/`DontDestroyOnLoad` bootstrap.** Each scene owns an independent `AudioManager` instance with identical Inspector wiring (`musicClipOverride: Assets/Audio/Music/music_nature_ambience.wav`, `guitarIntroClip: Assets/Audio/Music/music_guitar_intro.wav`, `birdsFillerClip: Assets/Audio/Music/music_birds_filler.wav` — copied from `SampleScene`'s existing `AudioManager`). Music restarting on the Play transition is expected and acceptable.
- `MainMenuUI` **only reads** `save.json` (via `SaveSummaryReader`); it never writes it. `SaveManager` remains the only writer, unchanged.
- **No changes** to `PlayerSaveData`, `MilestoneDefinition`, `SaveManager`, or any gameplay manager (`EconomyManager`, `TreePlanter`, `EmergenceSystem`, etc.).
- No new fields on `MilestoneDefinition` — milestone row text is generated from its existing `requirementType`/`requirementValue`/`rewardDailyFundsBonus`/`rewardGems`.
- This project has exactly one runtime assembly (`Grove.Runtime`, all of `Assets/Scripts` recursively) and one test assembly (`Grove.Tests`, references `Grove.Runtime`) — no assembly-boundary concerns for any new file.
- `Assets/Scenes/SampleScene.unity` is not modified by this plan at all.

```csharp
using System.Collections.Generic;
using System.IO;
using UnityEngine;

public static class SaveSummaryReader
{
    public struct SaveSummary
    {
        public bool SaveExists;
        public int TreesPlanted;
        public List<string> CompletedMilestoneIds;
    }

    public static SaveSummary ReadSummary(string savePath)
    {
        if (!File.Exists(savePath))
        {
            return Empty();
        }

        try
        {
            string json = File.ReadAllText(savePath);
            PlayerSaveData data = JsonUtility.FromJson<PlayerSaveData>(json);
            if (data == null)
            {
                return Empty();
            }

            return new SaveSummary
            {
                SaveExists = true,
                TreesPlanted = data.plantedTrees.Count,
                CompletedMilestoneIds = data.completedMilestoneIds
            };
        }
        catch (System.Exception)
        {
            return Empty();
        }
    }

    private static SaveSummary Empty()
    {
        return new SaveSummary
        {
            SaveExists = false,
            TreesPlanted = 0,
            CompletedMilestoneIds = new List<string>()
        };
    }
}
```

```csharp
using System.Collections.Generic;

public static class MilestoneLabelFormatter
{
    public static string FormatRequirement(MilestoneDefinition milestone)
    {
        switch (milestone.requirementType)
        {
            case MilestoneDefinition.RequirementType.TotalTreesPlanted:
                return $"Plant {milestone.requirementValue} trees";
            case MilestoneDefinition.RequirementType.SpeciesUnlockedCount:
                return $"Unlock {milestone.requirementValue} species";
            case MilestoneDefinition.RequirementType.FirstPredatorEmerged:
                return "Release your first predator";
            default:
                return milestone.id;
        }
    }

    public static string FormatReward(MilestoneDefinition milestone)
    {
        List<string> parts = new List<string>();

        if (milestone.rewardDailyFundsBonus > 0)
        {
            parts.Add($"+{milestone.rewardDailyFundsBonus} daily funds");
        }

        if (milestone.rewardGems > 0)
        {
            parts.Add($"+{milestone.rewardGems} gems");
        }

        return string.Join(", ", parts);
    }
}
```

```csharp
using System.Collections.Generic;
using System.IO;
using UnityEngine;
using UnityEngine.SceneManagement;
using UnityEngine.UIElements;

[RequireComponent(typeof(UIDocument))]
public class MainMenuUI : MonoBehaviour
{
    private const string GameplaySceneName = "SampleScene";

    [SerializeField] private List<MilestoneDefinition> allMilestones = new List<MilestoneDefinition>();
    [SerializeField] private SettingsUI settingsUI;

    private UIDocument uiDocument;
    private VisualElement confirmRoot;
    private VisualElement confirmFrame;
    private Label treesPlantedLabel;
    private Button playButton;
    private Button newGameButton;
    private ScrollView milestonesScroll;

    private string SavePath => Path.Combine(Application.persistentDataPath, "save.json");

    private void Awake()
    {
        uiDocument = GetComponent<UIDocument>();
    }

    private void OnEnable()
    {
        VisualElement root = uiDocument.rootVisualElement;

        confirmRoot = root.Q<VisualElement>("confirm-root");
        confirmFrame = root.Q<VisualElement>("confirm-frame");
        // Direct hide (not PanelAnimator): this is the initial startup state, not a
        // user-triggered close, so it must be instant with zero flash.
        confirmRoot.style.display = DisplayStyle.None;

        treesPlantedLabel = root.Q<Label>("menu-trees-planted");
        playButton = root.Q<Button>("play-button");
        newGameButton = root.Q<Button>("new-game-button");
        milestonesScroll = root.Q<ScrollView>("milestones-scroll");

        playButton.clicked += OnPlayButtonClicked;
        newGameButton.clicked += OnNewGameButtonClicked;
        root.Q<Button>("confirm-yes-button").clicked += OnConfirmYesButtonClicked;
        root.Q<Button>("confirm-no-button").clicked += OnConfirmNoButtonClicked;
        root.Q<Button>("settings-button").clicked += OnSettingsButtonClicked;
        root.Q<Button>("quit-button").clicked += OnQuitButtonClicked;

        Refresh();
    }

    private void Refresh()
    {
        SaveSummaryReader.SaveSummary summary = SaveSummaryReader.ReadSummary(SavePath);

        playButton.text = summary.SaveExists ? "Continue" : "Play";
        newGameButton.style.display = summary.SaveExists ? DisplayStyle.Flex : DisplayStyle.None;
        treesPlantedLabel.text = $"Trees planted: {summary.TreesPlanted}";

        RefreshMilestones(summary.CompletedMilestoneIds);
    }

    private void RefreshMilestones(List<string> completedMilestoneIds)
    {
        milestonesScroll.Clear();

        foreach (MilestoneDefinition milestone in allMilestones)
        {
            if (milestone == null || completedMilestoneIds.Contains(milestone.id))
            {
                continue;
            }

            VisualElement row = new VisualElement();
            row.AddToClassList("menu-milestone-row");

            Label requirementLabel = new Label(MilestoneLabelFormatter.FormatRequirement(milestone));
            requirementLabel.AddToClassList("menu-milestone-requirement");
            row.Add(requirementLabel);

            string reward = MilestoneLabelFormatter.FormatReward(milestone);
            if (!string.IsNullOrEmpty(reward))
            {
                Label rewardLabel = new Label(reward);
                rewardLabel.AddToClassList("menu-milestone-reward");
                row.Add(rewardLabel);
            }

            milestonesScroll.Add(row);
        }
    }

    private void OnPlayButtonClicked()
    {
        AudioManager.Instance?.PlayTap();
        SceneManager.LoadScene(GameplaySceneName);
    }

    private void OnNewGameButtonClicked()
    {
        AudioManager.Instance?.PlayTap();
        PanelAnimator.Open(confirmRoot, confirmFrame);
    }

    private void OnConfirmYesButtonClicked()
    {
        AudioManager.Instance?.PlayTap();

        if (File.Exists(SavePath))
        {
            File.Delete(SavePath);
        }

        SceneManager.LoadScene(GameplaySceneName);
    }

    private void OnConfirmNoButtonClicked()
    {
        AudioManager.Instance?.PlayTap();
        PanelAnimator.Close(confirmRoot, confirmFrame);
    }

    private void OnSettingsButtonClicked()
    {
        AudioManager.Instance?.PlayTap();
        settingsUI?.SetOpen(true);
    }
```

```csharp
using System.Reflection;
using NUnit.Framework;
using UnityEditor.SceneManagement;
using UnityEngine;
using UnityEngine.SceneManagement;

public class MainMenuSceneWiringTests
{
    private const string ScenePath = "Assets/Scenes/MainMenu.unity";

    private Scene loadedScene;

    [SetUp]
    public void SetUp()
    {
        loadedScene = EditorSceneManager.OpenScene(ScenePath, OpenSceneMode.Additive);
    }

    [TearDown]
    public void TearDown()
    {
        EditorSceneManager.CloseScene(loadedScene, true);
    }

    private static T FindComponent<T>() where T : Object
    {
        return Object.FindFirstObjectByType<T>(FindObjectsInactive.Include);
    }

    private static object GetPrivateField(object target, string fieldName)
    {
        FieldInfo field = target.GetType().GetField(fieldName, BindingFlags.NonPublic | BindingFlags.Instance);
        return field.GetValue(target);
    }

    [Test]
    public void MainMenuUI_Exists()
    {
        Assert.IsNotNull(FindComponent<MainMenuUI>());
    }

    [Test]
    public void MainMenuUI_SettingsUI_IsWired()
    {
        MainMenuUI menu = FindComponent<MainMenuUI>();
        Assert.IsNotNull(menu);
        Assert.IsNotNull(GetPrivateField(menu, "settingsUI"));
    }

    [Test]
    public void MainMenuUI_AllMilestones_HasFiveEntries()
    {
        MainMenuUI menu = FindComponent<MainMenuUI>();
        Assert.IsNotNull(menu);
        System.Collections.IList milestones = (System.Collections.IList)GetPrivateField(menu, "allMilestones");
        Assert.AreEqual(5, milestones.Count);
        foreach (object milestone in milestones)
        {
            Assert.IsNotNull(milestone);
        }
    }

    [Test]
    public void SettingsUI_Exists()
    {
        Assert.IsNotNull(FindComponent<SettingsUI>());
    }

    [Test]
    public void AudioManager_Exists()
    {
        Assert.IsNotNull(FindComponent<AudioManager>());
    }

    [Test]
    public void BuildSettings_ContainMainMenuAndSampleScene_InOrder()
    {
        UnityEditor.EditorBuildSettingsScene[] scenes = UnityEditor.EditorBuildSettings.scenes;
        Assert.GreaterOrEqual(scenes.Length, 2);
        StringAssert.Contains("MainMenu.unity", scenes[0].path);
        StringAssert.Contains("SampleScene.unity", scenes[1].path);
    }
}
```
